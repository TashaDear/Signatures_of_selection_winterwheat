Title: Temporal changes in allele frequency facilitate detection of adaptive variants in winter wheat (Triticum aestivum L.) breeding programs

Description

This repository contains code associated with the manuscript:

Johansen, N.H. et al. Temporal changes in allele frequency facilitate detection of adaptive variants in winter wheat breeding programs.

The study investigates whether temporal trends in allele frequency can be used to identify non-neutral genetic variants in a winter wheat breeding population. Selection signatures were inferred using a generalized linear mixed model and evaluated for their association with agronomic traits and their utility in genomic prediction models.

Contents
Scripts/: R scripts used for data processing, statistical analyses, and figure generation.
